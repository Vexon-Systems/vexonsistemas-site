# Capas dos projetos

Coloque aqui a imagem de capa de cada projeto, por exemplo:

- `sellion-pdv.webp`
- `consultor-hub.webp`
- `telemetria-pivos.webp`

Depois abra `src/content/home.ts` e atualize somente o campo `coverImage` do projeto:

```ts
coverImage: "/assets/projects/sellion-pdv.webp",
```

Enquanto o valor estiver como `null`, a landing page usa o placeholder visual atual automaticamente.
