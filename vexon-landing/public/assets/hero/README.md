# Assets da Hero

Adicione os dois arquivos abaixo nesta pasta:

- hero-desktop.webp — proporção recomendada 16:10, com pelo menos 1600px de largura.
- hero-mobile.webp — proporção recomendada 9:19, com pelo menos 700px de largura.

Os caminhos ficam centralizados em src/content/home.ts, no objeto heroDeviceAssets.

Enquanto os dois arquivos não existirem, os mockups exibem telas provisórias. Ao adicionar ambos os assets, elas são substituídas automaticamente.
